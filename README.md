kantin.c adalah program konsol C untuk memantau stok dan penjualan kantin kampus (mata kuliah Algoritma dan Pemrograman Lanjutan). Data disimpan dalam array paralel (nama, harga, stok, terjual, pendapatan) dengan kapasitas maksimal 50 produk, dan hilang saat program ditutup karena tidak disimpan ke file. Program dimulai dengan enam produk contoh seperti Nasi Goreng, Mie Ayam, dan Es Teh. Lewat menu berulang, pengguna bisa melihat, menambah, dan mengubah produk, mencatat transaksi penjualan dengan keranjang dan struk, menambah stok, mencari produk berdasarkan sebagian nama, mengurutkan produk dengan bubble sort (harga termurah atau terjual terbanyak), melihat laporan penjualan beserta produk terlaris, dan mengecek stok menipis (di bawah 5). Validasi inputnya baik: memakai fgets dan strtol, menolak angka negatif, nama kosong, dan nama duplikat. Kekurangannya, belum ada fitur hapus produk dan penyimpanan data permanen.
